# docs

Team-level material only. Anything that belongs to one component lives in
`components/<cN>/research/`.

| Folder | Contents |
|---|---|
| `proposal/` | Team proposal presentation, topic assessment form (TAF) |
| `templates/` | SLIIT proposal report template, presentation structure guide |
| `architecture/decisions/` | Architecture decision records |

## Files

| File | What it is |
|---|---|
| `proposal/Team_Proposal_Presentation.pdf` | Team proposal deck (all four components) |
| `proposal/TAF_Topic_Assessment_Form.pdf` | Topic assessment form |
| `templates/SLIIT_Proposal_Report_Template.pdf` | Required structure for the proposal report |
| `templates/SLIIT_Proposal_Presentation_Structure.md` | Slide-by-slide structure and marking weights for the proposal presentation |

Diagrams live in each component's own `research/diagrams/` folder, not here.

PDFs and images are stored with Git LFS. Run `git lfs install` once before committing.
