## Contract rules

Essential claims must cover every non-whitespace character of the supplied required passages. Claims bind exact current text spans, action ownership and source evidence. Required claims cannot be placed only in disclosable remainders or supplementary text. All effective source conditions remain visible. Detailed shares the same essential layer as Concise and must add reviewed clarification. Disclosure ON requires a reviewed, meaningful remainder for the selected depth; one qualifying step is enough. OFF leaves that explanation visible.

Review status alone is insufficient: usable paraphrases require a named source-fidelity record, statement-level checks, evidence and matching content/source fingerprints. Mock material cannot be relabelled reviewed; fictional authored reviews cannot approve an official graph. These are integrity/coverage checks, NOT automated proof of semantic entailment, factual completeness or reviewer authenticity. Human comparison remains necessary. Authentication/editorial publication integration is a later phase.

Facts retain original source values. Explicit attachments distinguish action, route, stage and service scopes; route conditions remain attached. Stage membership or mention does not imply an action payment. Unreviewed attribution falls back to Plan stage scope. There is no computed fee total. Tests exercise all four scopes, wrong targets, missing route conditions and cross-stage contradictions.

Recap ON requires reviewed reminder wording for all actions and more than one action; visited-step eligibility remains future journey instrumentation. Segmentation ON needs reviewed useful phase labels, declared grouping basis and orientation attestation, complete unique membership and explicit notes for branch splits. Ordering requires reviewed source support and cannot contradict verified dependencies. Groups alone imply no execution order.

Guided requires complete action/condition/branch/prerequisite/service-dependency coverage and multiple actions. Map additionally requires complete parallel coverage and actual supplied relationships. Unknown coverage fails closed. Existing official snapshots therefore still cannot offer full maps. Hard locks and accessibility constraints intersect with content/structure feasibility; conflicting constraints produce no candidates, never a silent relaxation.
